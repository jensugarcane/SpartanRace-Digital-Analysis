# Spartan Race Digital Performance Analysis
This project focuses on analyzing and visualizing 393 Facebook posts from Spartan Race (30 Aug - 15 Oct 2016). The analysis includes data cleaning, transformation, and the creation of an interactive dashboard using Power BI.
# Project Objectives
Preprocess raw Spartan Race's Facebook activities data using Excel.
Transform and enrich the dataset with calculated columns (post type, content pillar, day of week, time of day).
Visualize key insight via Power BI dashboard and interactive Excel dashboard.
Recommend a strategy to optimize content and enhance engagement.
# Tools Used
Microsoft Excel - For data cleaning and transformation (Pivot Table, VLOOKUP, etc,.).
Power BI – For building interactive and insightful dashboards.
# Key Insights Presented
Content distribution and engagement performance across photo, video, status, and link posts.
Comment rate and engagement potential of underutilized formats.
Posting Frequency: Daily posting volume, engagement per post, and optimal posting frequency.
Day of Week: Engagement performance and post volume across weekdays and weekends.
Hour of Day: Peak engagement hours and average engagement per post.
# Dataset
Source: Spartan Race Facebook page post data (case study dataset)
Time range: 30 Aug - 15 Oct 2016 (47 days)
Includes 393 posts, including post type (photo, video, link, status, event), content pillar, posting date/time, and engagement metrics (likes, comments, shares).
# Outcome
The results reflect the metrics needed for content performance analysis. The final dashboard enables analysis across **Post Type, Content Pillar, Day of Week, Hour of Day and Time of Day**.
* Findings were turned into a **3-part action plan** (format, frequency, scheduling) and a sample content calendar.
# Dashboard Review

## Recommendations

1. **Diversify content format** – Rebalance photo and video, test status posts, and curate high-value link posts.
2. **Invest in quality, not quantity** – Limit daily posts to 6–10 to protect content quality and organic reach.
3. **Refine post scheduling** – Add posts on Saturday, add slots at 12:00–13:00 and 01:00, keep 15:00 and 18:00, and cut back 14:00, 16:00–17:00 and 23:00.
